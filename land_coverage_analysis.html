The synthetic data is based on documented deforestation rates from FAO and World Bank reports (~0.7% annual forest loss).

World Bank API Endpoints

This script attempts to download data from the following World Bank Development Indicators:

  • Forest Coverage: AG.LND.FRST.ZS (Forest area % of land area)
  • Agricultural Land: AG.LND.AGRI.ZS (Agricultural land % of land area)
  • Urban Population: SP.URB.TOTL.IN.ZS (Urban population %)

Download Code

import requests
import pandas as pd

# Download forest data from World Bank API
url = "https://api.worldbank.org/v2/country/COD/indicator/AG.LND.FRST.ZS"
params = {
    'format': 'json',
    'date': '2015:2023',
    'per_page': 100
}

response = requests.get(url, params=params)
data = response.json()

forest_data = {}
for item in data[1]:
    year = int(item['date'])
    value = item['value']
    if value is not None:
        forest_data[year] = float(value)
